# Marketplace Analytics & Conversion Funnel Definitions

## Key Performance Indicators (KPIs)
- **Gross Merchandise Value (GMV)**: Total monetary value of completed service bookings.
- **Net Revenue**: Platform marketplace commission (10% fee).
- **Booking Conversion Rate**: `(Completed Bookings / Created Bookings) * 100`
- **Provider Fulfillment Rate**: `(Completed Bookings / Accepted Bookings) * 100`
- **Customer Retention Rate**: Percentage of customers making 2+ bookings within 30 days.
