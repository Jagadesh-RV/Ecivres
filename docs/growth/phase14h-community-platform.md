# Phase 14H — Community Platform & Knowledge Hub

## Feature Set
1. **Community Discussions**: User-generated posts and maintenance advice.
2. **Provider Showcases**: Highlighting high-impact Before/After renovation transformations.
3. **Q&A Advice Feed**: Verified provider answers to home maintenance questions.

## APIs
- `POST /community/post`: Create discussion post.
- `GET /community/showcases`: Fetch provider showcases.
- `POST /community/ask`: Ask Q&A question.
