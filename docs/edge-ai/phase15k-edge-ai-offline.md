# Sprint 15K — Edge AI & Offline Intelligence

## Overview
Edge AI & Offline Intelligence enables edge node neural network inference with sub-5ms latency, offline recommendation caching, regional routing, and edge state synchronization.

## APIs
- `POST /edge-ai-v2/inferences`: Dispatch offline sub-5ms Edge AI inference.
- `GET /edge-ai-v2/nodes/:id/latency`: Get sub-5ms edge latency metrics for regional node.
