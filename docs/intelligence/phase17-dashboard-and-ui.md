# Phase 17 Intelligence Dashboard & Mobile UI Documentation

## Web Components
- `DecisionIntelligenceDashboard`: Top-level overview displaying aggregate market health scores (e.g. 94.8%), active anomaly counts, and 24h autonomous decision execution totals.
- `AnomalyAlertPanel`: Live streaming anomaly alerts with single-click manual/automated resolution controls.
- `PolicyGuardrailConfigurator`: Executive configuration interface for dynamically updating strict surge percentage caps and daily autonomous financial limits.

## Mobile UI Screens
- `ExecutiveDecisionScreen`: React Native screen allowing executives to review and approve/reject high-risk policy decisions flagged by soft-guardrail thresholds.
- `MarketHealthMapScreen`: Mobile geospatial visualization showing regional market friction scores and supply constraints.
