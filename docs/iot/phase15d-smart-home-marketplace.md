# Sprint 15D — Smart Home IoT Marketplace

## Overview
The Smart Home IoT Marketplace integrates MQTT telemetry streaming, device health monitoring, predictive maintenance algorithms, and automated booking triggers.

## APIs
- `POST /smart-home-iot/devices`: Register smart home IoT telematics device.
- `POST /smart-home-iot/devices/:id/predictive-booking`: Trigger automated predictive maintenance booking.
