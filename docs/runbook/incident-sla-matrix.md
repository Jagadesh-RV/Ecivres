# Incident Severity & SLA Response Matrix

| Severity | Definition | Target Response Time | Target MTTR |
| :--- | :--- | :--- | :--- |
| **SEV-1** | Critical outage, core payment / booking failure | **5 Minutes** | **< 30 Minutes** |
| **SEV-2** | Major service degradation, partial feature loss | **30 Minutes** | **< 2 Hours** |
| **SEV-3** | Minor operational issue, non-blocking bug | **2 Hours** | **< 24 Hours** |
| **SEV-4** | Cosmetic / minor enhancement request | **Next Sprint** | **N/A** |
