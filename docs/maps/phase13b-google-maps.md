# Phase 13B — Google Maps & Places Integration

## Overview
Integrates Google Places Autocomplete, Geocoding, Reverse Geocoding, Routes API, Distance Matrix, and real-time ETA recalculations.

## APIs
- `GET /google-maps/autocomplete`: Places autocomplete suggestions.
- `GET /google-maps/geocode`: Address to lat/lng geocoding.
- `GET /google-maps/reverse-geocode`: Lat/lng to address reverse geocoding.
- `GET /google-maps/route`: Routes API direction calculation.
