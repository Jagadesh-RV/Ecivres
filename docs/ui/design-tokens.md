# EcivreS UI Design Tokens & Theme Specification

## Core Color System
- **Primary Accent**: Slate / Indigo (`#6366f1` / `indigo-600`)
- **Success / Completed**: Emerald (`#10b981` / `emerald-500`)
- **Warning / Pending**: Amber (`#f59e0b` / `amber-500`)
- **Danger / Cancelled**: Rose (`#f43f5e` / `rose-500`)
- **Dark Mode Background**: Dark Slate (`#0f172a` / `slate-900`)

## Typography & Glassmorphism
- **Font Family**: Inter, sans-serif
- **Glassmorphism Backdrop**: `backdrop-blur-md bg-white/80 dark:bg-slate-900/80`
- **Card Radius**: `rounded-2xl`
