# Automated Release Reporting Specification

## Generated Audit Artifacts
- `deployment-report.md`: Environment & gate verification sign-off.
- `security-report.md`: GPG signature, OWASP scan, secret scan results.
- `performance-report.md`: Latency, error rate & throughput benchmarks.
- `test-report.md`: Unit & synthetic smoke suite pass rates.
- `rollback-readiness-artifact.md`: Snapshot ID & target RTO/RPO limits.
- `commit-summary.md`: Conventional commit lint summary.
